## 思维导图

用 ```mindmap 围栏代码块，按缩进表示层级：

```mindmap
SecNotes
  写作
    Markdown 语法
    双向链接 [[笔记]]
  发布
    本地构建
    GitHub Pages
  维护
    分类与标签
    统计与搜索
```

## 双向链接

用 `[[笔记标题]]` 引用其他笔记：

- 已经存在的笔记会生成**出链**与**入链**：比如 [[Markdown 基础语法]]
- 尚未创建的目标会进入「待创建」列表，方便后续补写

## 阅读统计

构建时自动统计字数与阅读时长。中文字符按 1 字、英文单词按 1 词计数：

```text
CJK 字符数 + 英文单词数 = 总字数
```
