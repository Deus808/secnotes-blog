## 这是什么

SecNotes 是一个基于 Markdown 的**个人知识笔记库**：把 `notes/` 目录下的 Markdown 笔记
构建成前端可直接读取的 `data/notes.js`，双击 `index.html` 即可离线浏览，构建一次即可发布到
GitHub Pages，全程无数据库、无后端。

## 核心功能

- **front-matter 元数据**：每篇笔记开头用 `---` 声明标题、日期、分类、标签，站点自动归档与聚合
- **分类 / 标签 / 归档**：侧边栏按分类与标签聚合，归档页按时间倒序浏览
- **全文搜索**：按 `/` 聚焦搜索框，实时过滤全部笔记
- **双向链接**：`[[笔记标题]]` 自动生成出链 / 入链视图，尚未创建的标题会进入「待创建」
- **思维导图**：用 ```mindmap 围栏代码块渲染内联 SVG，自动跟随明暗主题
- **明暗主题**：右上角一键切换，偏好本地记忆
- **阅读统计**：字数、预计阅读时长自动计算，构建时写入

## 快速开始

```bash
# 1. 构建（扫描 notes/ 生成 data/notes.js）
python build.py

# 2. 打开站点
# 直接双击 index.html 即可；命令行下可运行：
python -m http.server 8090 --bind 127.0.0.1
```

## 开始写作

- 直接编辑 `notes/*.md` 后重新构建；
- 或用管理端：双击 `start-admin.bat`（见 README 的「写作」一节）。
